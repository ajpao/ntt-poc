# NTT-POC — POC Simulator: Hypervisor & Backup Software

Interactive single-page simulator สำหรับนำเสนอ Proof of Concept (POC) ด้าน Hypervisor และ Backup Software

## วิธีเปิดใช้งาน

- **Primary (Firebase Hosting):** [https://ntt-poc.web.app](https://ntt-poc.web.app)
- **Backup (Netlify):** [https://ntt-poc.netlify.app](https://ntt-poc.netlify.app)
- **Backup (GitHub Pages):** [https://ajpao.github.io/ntt-poc/poc.html](https://ajpao.github.io/ntt-poc/poc.html)

## ภาพรวม

ไฟล์ poc.html เป็น standalone HTML ที่จำลองสถานการณ์การทดสอบ Hypervisor และ Backup Software ในรูปแบบ dark-theme dashboard พร้อม animation ให้ใช้นำเสนอต่อลูกค้าหรือทีมงาน

## เทคโนโลยีที่ใช้

- HTML5 / CSS3 / Vanilla JavaScript
- Firebase Realtime Database (real-time sync ข้าม session)
- Firebase Hosting (primary hosting)
- Google Fonts: Share Tech Mono, Noto Sans Thai

## หมายเหตุ

ไฟล์นี้เป็น POC สำหรับใช้ภายในและการนำเสนอเท่านั้น
